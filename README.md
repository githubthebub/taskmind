# Sensory Rewire

Offline-first sensory re-indexing grid and neuro-somatic focus accelerator. A
client-side web/mobile PWA combining a 4-7-8 breathing guide with synchronized
binaural audio, haptic sequencing, and cognitive-reframing prompts — zero cloud
services, zero external APIs, zero runtime dependencies.

Full architecture and build log: [`SENSORY_REWIRE_SYSTEM.md`](./SENSORY_REWIRE_SYSTEM.md)

## Target states

- **Somatic Rapture (Pīti Matrix)** — cascading micro-pulse haptics, wide binaural offsets, euphoric re-indexing scripts
- **Deep Equanimity (Sukha Base)** — slow spatial drift, near-silent haptics, spacious equanimity scripts
- **Peak Cognitive Acceleration (Flow State)** — metronomic haptics, tight modulation, executive-focus scripts

One selection retunes the sound, tactile, and text engines simultaneously from
a single state configuration object.

## Run it

The compiled app is checked in — any static file server works:

```sh
npm run serve        # http://localhost:4173
```

Or rebuild from TypeScript source:

```sh
npm install
npm run build        # tsc → dist/
```

Install to a phone home screen from the browser menu for standalone offline
use (haptics require a device with a vibration motor; use headphones for the
binaural layer).

## Notes

This is a meditation/attention-training tool, not a medical device. Frequency
and script choices are practice framing, not clinical claims.
